# Book Review Application — IBM Skills Network

Node.js + Express REST API implementation for the course final project.

Includes all public book endpoints (catalog, ISBN, author, title, reviews), registration and session/JWT login, authenticated review add/update/delete, four Axios Async/Await examples, and a real cURL evidence collector.

## Run the application

~~~bash
cd final_project
npm install
npm start
~~~

Server: http://localhost:5000 (default). In another terminal, run:

~~~bash
bash capture_evidence.sh DEEMALAJLAN132005
~~~

This saves the actual cURL commands and JSON outputs under final_project/evidence/ for the AI-graded submission. Do not invent or reuse outputs from a different run.

## API routes

Public: GET /, GET /isbn/:isbn, GET /author/:author, GET /title/:title, GET /review/:isbn, POST /register.

Authenticated: POST /customer/login; PUT /customer/auth/review/:isbn?review=...; DELETE /customer/auth/review/:isbn. Carry the session cookie from login when calling authenticated routes.

Async Axios demonstrations: GET /async/books, GET /async/isbn/:isbn, GET /async/author/:author, GET /async/title/:title. All four corresponding exported functions live in final_project/router/general.js.

## Evaluation

This repository is forked from ibm-developer-skills-network/expressBookReviews. The final assignment's Task 10 uses the public GitHub URL of final_project/router/general.js. Task 11 uses the githubrepo cURL output generated by the evidence script.

An automated GitHub Actions test job is configured under .github/workflows/verify.yml; its artifact includes live cURL command/output evidence after a successful run.

## Important

This is a course demo. Accounts, sessions, and reviews are kept in memory and reset when the server restarts. Set strong JWT_SECRET and SESSION_SECRET variables in a real deployment. Do not use the development fallback secrets publicly.
